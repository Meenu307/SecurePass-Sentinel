# SecurePass-Sentinel 🛡️

A modern web application designed to help users check, generate, and manage secure passwords effectively.

## 🔗 Live Demo
* **Live Website:** https://secure-pass-sentinel.vercel.app/

---

## Features
* **Password Strength Checker:** Analyzes password entropy and security levels in real-time.
* **Secure Password Generator:** Creates strong, randomized passwords based on custom criteria.
* **Modern & Responsive UI:** Built for a seamless experience across devices.
